# DEPRECATED — `iucnranges/`

**Status:** deprecated 2026-07-02. Reference only; not actively developed.

This R package stub (IUCN range fetching, map building, species filtering) is
**superseded by the Golem app `edna-viz/`**, which implements the visualization
layer (BLAST upload → threshold filter → Leaflet map with IUCN ranges + GBIF
occurrences + eDNA sampling sites).

Do not build on this package. See `scripts/README.md` and the project
consolidation plan. Retained for reference and git history only.
